# BETONCHI FINAL
Mobil öncelikli sanal bebek sürümü.

## GitHub + Vercel
1. ZIP'i açın.
2. Bu klasörün İÇİNDEKİ index.html, style.css, app.js, manifest.json ve assets klasörünü GitHub BETONCHI reposunun ana dizinine yükleyin.
3. Commit changes.
4. Vercel'de repo bağlıysa yeni deployment otomatik başlar; değilse Import Project > repo > Deploy.

Özellikler: tek Beton odaklı ekranlar, yemek seçimi ve yeme tepkisi, dört kombin ve karakter üstü görsel katman, prova, dinlenme, konser, kalıcı durum değerleri.
