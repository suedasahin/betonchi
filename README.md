# BETONCHI SIMPLE V4

Bu sürüm özellikle sade mobil UX için yeniden yazıldı.

## GitHub / Vercel
1. GitHub BETONCHI reposundaki eski `index.html`, `style.css`, `app.js`, `manifest.json` ve eski `assets` içeriğini silin.
2. Bu ZIP'i açın.
3. ZIP'in içindeki `index.html`, `style.css`, `app.js`, `manifest.json` ve `assets` klasörünü repository'nin ana dizinine yükleyin.
4. Commit changes.
5. Vercel bağlıysa yeni commit otomatik deploy olur. Olmazsa Vercel > Project > Deployments üzerinden Redeploy yapın.

## Tasarım
- Alt menü tek satırdır ve üst üste binmez.
- 5 gerçek ekran vardır: Ana, Yemek, Kombin, Konser, Beton.
- Her ekranda tek ana karakter karesi vardır.
- Yemek seçimi, durum değerleri, prova/dinlenme ve konser mantığı çalışır.
- Kombin ekranındaki kıyafet parçaları gerçekten görünür biçimde değişir.
